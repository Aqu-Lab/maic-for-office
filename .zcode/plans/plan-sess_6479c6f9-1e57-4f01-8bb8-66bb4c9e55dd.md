# GenOffice → Obsidian 插件：Office 文件查看器

## 目标

在 monorepo 内新增一个 Obsidian 插件 workspace，在 Obsidian 中点击 vault 里的 `.docx / .pptx / .xlsx` 附件即可直接预览。只做查看，不做编辑；旧格式 `.doc/.ppt/.xls` 暂不支持。

## 核心结论（已验证）

- **解析引擎可直接复用且浏览器兼容**：`docx-engine` 的 `parseDocx(Uint8Array)`、`pptx-engine` 的 `openPptx(Uint8Array)`、`pptx-render` 的数据驱动 RenderTree 均不依赖 Electron。个别 `node:fs/crypto` 引用（字体定位、hash）在 Obsidian **桌面版**的 Node 环境中可用。
- **pptx 渲染复用度高**：`apps/slides/src/renderer/konva-adapter.ts` 是薄适配层（RenderTree → Konva 属性映射），保真逻辑全在 `pptx-render` 里，可整体复制为只读画布。
- **xlsx 需换解析层**：原实现走 Rust sidecar（无法打进插件），改用 SheetJS CE（纯 JS）解析 + 自建表格视图。
- **docx 渲染层自建**：解析用 `parseDocx` → 块树，为只读场景新写 HTML/CSS 渲染器，不移植 apps/docs 的编辑器。

## 新增 workspace：`apps/obsidian-plugin`

```
apps/obsidian-plugin/
├── package.json          # @genoffice/obsidian-plugin，依赖引擎包 + esbuild + obsidian 类型
├── esbuild.config.mjs    # 打包 main.js（node: 内置模块标 external；产物复制到测试 vault）
├── manifest.json         # id/name/version/minAppVersion（品牌避开 GenOffice 商标，建议 "Office Viewer"）
├── styles.css
└── src/
    ├── main.ts           # Plugin 入口：registerExtensions(['docx','pptx','xlsx']) + registerView
    ├── file-io.ts        # TFile → vault.adapter.readBinary → Uint8Array
    ├── settings.ts       # 设置页（缩放默认值等，从简）
    └── views/
        ├── base-view.ts  # 公共 ItemView 基类：加载态/错误态/关闭清理
        ├── docx-view.ts  # + render/docx-renderer.ts（块树 → 只读 HTML：标题/段落/字符样式/列表/表格/图片/超链接，分页视图简化版）
        ├── pptx-view.ts  # + render/pptx-canvas.ts（RenderTree → Konva Stage 只读；幻灯片缩略图侧栏 + 单页画布 + 缩放）
        └── xlsx-view.ts  # + render/xlsx-table.ts（SheetJS 解析 → sheet 切换 + 虚拟滚动表格）
```

- 渲染层用**纯 DOM + Konva**，不打包 React（三个只读视图都不需要 React 状态管理，省体积、避免与宿主冲突）。
- 字体：pptx 文本布局需要字体 metrics。第一版内嵌 monorepo 已带的打包字体（`apps/slides/src/renderer/fonts`、`packages/ui/src/fonts`）+ 合理 fallback；读取系统字体（`font-metrics` 的 node:fs 路径）作为后续增强。

## 集成要点

- 扩展名注册：`registerExtensions(["docx","pptx","xlsx"])` 接管打开方式；`registerView` 提供对应 ItemView。
- 打包产物：`main.js` + `manifest.json` + `styles.css`，esbuild 构建后自动拷贝到测试 vault 的 `.obsidian/plugins/office-viewer/`（vault 路径走 package.json 配置或环境变量）。
- 引擎包以 workspace 源码形式直接进 esbuild（monorepo 现有 exports 指向 `src/index.ts`，无需预编译）。

## 实施顺序（全做，分阶段提交）

1. **插件骨架**：workspace + esbuild + manifest + 视图注册 + 二进制读取 + 错误 UI；用一个 `.docx` 走通「点击 → 打开视图」。
2. **docx 查看器**：块树渲染器（结构化保真，非 Word 级逐像素分页）。
3. **pptx 查看器**：复用度最高，重点验证字体 metrics 在插件内的加载。
4. **xlsx 查看器**：SheetJS + 虚拟滚动表格（第一版优先数值/文本正确，样式从简）。
5. **打磨**：明暗主题适配（文档区域保持白底，遵循项目"dark chrome, white paper"原则）、大文件性能、README/使用说明。

## 范围外（明确不做）

- 编辑与保存、PDF、AI 功能、Genspark 登录
- `.doc/.ppt/.xls` 旧格式（后续可用 file-parse 做文本提取式查看）
- Obsidian 移动端（无 Node 环境，引擎的 node: 依赖不可用）
- 社区插件市场上架流程（先本地可用，上架另议）

## 风险与预期

- bundle 预计 3–5 MB（jszip/fast-xml-parser/opentype.js/konva/SheetJS），桌面版可接受。
- docx 预览保真度为"结构良好、样式接近"，与 Word 原生分页有差距；pptx 保真度最高（直接复用经测试的渲染引擎）；xlsx 样式保真度第一版最低。
- 引擎包当前是 `private: true` 的 ESM workspace，插件 workspace 直接吃源码打包，不改它们的配置。
